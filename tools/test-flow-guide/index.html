Hướng dẫn test riêng

Test project theo từng flow

Biết bắt đầu ở đâu, dùng role nào và kiểm tra kết quả gì sau mỗi bước.

Manager tiếp nhận→HLV / Vet chuẩn bị→Groom chăm sóc→HLV tập / thi đấu→Owner kiểm tra
Chuẩn bị trước khi test
  1. Chuẩn bị 5 tài khoản đang hoạt động: Manager, HLV, Vet, Groom, Owner.
  2. Tạo ngựa TEST Sao Mai; gán Owner / HLV / Vet / Groom, chuồng và vật tư có tồn kho.
  3. Web và mobile trỏ cùng backend. Dùng nhiều profile hoặc đổi tài khoản ở mỗi bước.
  4. Chọn buổi tập còn khoảng 10 phút, kiểm tra giờ/policy thật. Không đổi đồng hồ để vượt điều kiện.
  5. Test nhánh khóa tập/archive trên ngựa khác. MongoDB cần replica set cho ghi việc/kho và tiền thưởng.

Groom có thể dùng mobile hoặc web test tạm khi bật cờ. Offline/camera thực tế phải thử trên điện thoại.

Chọn Đạt/Lỗi sau khi bạn thực sự thao tác. Kết quả test tự động trước đó không tự đánh dấu test tay.

Trang độc lập với ứng dụng project. Hướng dẫn đối chiếu flow hiện tại và checklist trong repo; không tự thực hiện thao tác trên project.
